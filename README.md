# Trabajo práctico 01 — Fundamentos de Node.js

## Descripción
Este repositorio contiene la solución del TP01. El proyecto genera la ficha técnica de un videojuego en la terminal y en un archivo de texto plano de manera dinámica, además de incluir una demostración práctica sobre el funcionamiento del Event Loop en Node.js.

## Cómo ejecutar

1. ** Ejecutar la ficha de videojuego (con nombre alternativo por defecto): Estudiante Anónimo
      node index.js
2. ** Ejecutar la ficha de videojuego (Ingresar un nombre) Ejemplo:  Sebastian
      PS D:\DiplomaturaProgramacionFullStack\tp-01-fundamentos-node> node index.js Sebastian
